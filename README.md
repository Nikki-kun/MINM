# MINM Messenger

Уникальный линукс-мессенджер на C++.

## Структура проекта

- `include/core/` - основные сущности (пользователи, группы, сообщения, контакты)
- `include/managers/` - менеджеры для управления сущностями
- `src/` - исходный код

## Особенности

- Управление группами без отдельного менеджера чатов
- Добавление пользователей происходит через группы
- Гибкая система уведомлений
- Поддержка различных типов групп (диалоги, группы, каналы)
